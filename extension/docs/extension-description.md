# Class-Navi Quick Tools — Product Description

> Status: draft (2026-08-11). Written from the extension README feature list.

## Product title

**Class-Navi Quick Tools — study patterns, speed grading & student stats for Kumon instructors**

## One-liner

Assign work in the patterns you actually use (4-3-3, 3-2-3-2, 2-2-2-2-2) with one
click — then grade faster, leave precise red-ink comments, and see your students'
study stats without counting by hand.

## Full description

**Class-Navi Quick Tools makes daily assigning and marking dramatically faster —
entirely inside the Class-Navi screens you already use. No new windows, no extra
dashboards, no learning curve.**

### Assign homework in your own study patterns

Break 10-page blocks into session segments the way you teach: **4-3-3, 3-2-3-2,
2-2-2-2-2**, or any pattern you define. One click reshapes every matching day in
the set editor — a 20-page block becomes your pattern twice, and so on. Days
you've **already split are never touched**, so your carefully formatted work
stays exactly as you set it. Unsaved drag-created blocks are handled too.

### Grade a whole page in one click

Mark every problem on a page correct or wrong instantly — click the toolbar
button or use the keyboard (**A** = all correct, **S** = all wrong). No more
clicking through question by question.

### Typed red-ink comments, placed exactly where you mean

Click where you want a note, type (multiline supported), and your comment
renders as **natural red pen ink right on the worksheet** — with font size and
style control (cursive, print, bold). Smart auto-calibration places text
precisely; a manual corner-calibration mode fine-tunes placement to the pixel.

### Erase all ink in one click

Clear the entire red layer — typed comments and pen marks — instantly.

### Know your students at a glance

A compact stats chip in the editor shows **average and median pages and time per
study session** for the current student and level. The assign screen adds level
stats: **total pages assigned, average repeat rate, and days between
assignments** — the numbers you'd otherwise count by hand.

### Private by design

Installs in minutes as a browser extension (Edge/Chrome), runs entirely inside
the Class-Navi page, and uses **only your existing Class-Navi session** — no
separate accounts, no data leaves your browser. All saves go through Class-Navi's
own app, exactly as if you'd clicked Save yourself.

## Feature summary (for listing bullets)

- One-click study patterns: 4-3-3, 3-2-3-2, 2-2-2-2-2, custom patterns
- Only touches full 10-page blocks; already-split days are never re-flattened
- Mark-all-correct / mark-all-wrong per page (toolbar + A/S keyboard shortcuts)
- Typed comments rendered as red pen ink: multiline, font size 24–72, cursive/
  print/bold styles, pixel-exact placement (auto + manual calibration)
- Erase-all-ink button clears the full red layer
- Study-session stats chip: avg/median pages + time per session (per student/level)
- Level stats: pages assigned, average repeat rate, assignment gap avg/median
- Works in the app's own UI — no new panels, no separate dashboards
- Uses only the existing Class-Navi login session; saves via Class-Navi's own app
- Install: Edge/Chrome, load-unpacked extension
